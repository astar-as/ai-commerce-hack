## PLAN.md is the shared source of truth

Four people are building in parallel. `PLAN.md` is how everyone knows what the others are working on, so keep it current:

- **Read `PLAN.md` before starting any task**, and pull `main` first so you see the latest version. Check the team split, tool interfaces and timeline before touching shared code.
- **Update `PLAN.md` whenever something changes**: you start or finish a piece of work, an interface or shared type changes, a decision is made, or a plan is dropped. Note who owns what and its status.
- **Push `PLAN.md` changes to `main` promptly**, in a small separate commit, so teammates on other branches can pull them right away.
- If the code and `PLAN.md` disagree, fix whichever is wrong in the same session rather than leaving it.
